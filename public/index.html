Protection Layer

Multiple security steps protect your file throughout the process.

✓
File Segmentation Large files are divided into smaller blocks.
✓
AES-256-GCM Encryption Every block is encrypted before cloud storage.
✓
Private Amazon S3 Encrypted blocks remain inside a private S3 bucket.
✓
Secure Reconstruction Blocks are decrypted and reconstructed during download.

How CloudVault Works

From your device to secure cloud storage and back.

01

Select File

Choose a file from your device that you want to protect.

02

Split & Encrypt

The file is divided into blocks and each block is encrypted.

03

Store in AWS

Encrypted blocks and their manifest are stored in private Amazon S3.

04

Download & Restore

Blocks are retrieved, decrypted and reconstructed into the original file.
